# Gestor de Instrumentos – Proyecto de Especialidad

Sistema web de gestión de inventario, arriendo y mantenciones de instrumentos musicales.
Autor: Daniel Rodríguez Salazar · Docente: Iván Ayala · AIEP, Taller de Proyecto de Especialidad (TPE058)

## Prototipo en línea
Abrir el sitio de GitHub Pages de este repositorio (archivo `index.html`).

Acceso:
- Sin correo: botones **Entrar como Administrador** o **Entrar como Operador**.
- Con correo: `admin@tienda.cl` / `admin123` (Administrador) o `operador@tienda.cl` / `operador123` (Operador).

El prototipo implementa las 13 historias de usuario del informe (HU-01 a HU-13). La pestaña **Trazabilidad** relaciona cada historia con su pantalla. Los datos son de ejemplo y se guardan solo en el navegador.

## Código Django
`backend_django.zip` contiene el proyecto Django (Python + PostgreSQL) con HU-03 (Registrar instrumento) y HU-08 (Registrar arriendo), sus pruebas y un README con las instrucciones para ejecutarlo.
